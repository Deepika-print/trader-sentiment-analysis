# 📊 Trader Performance vs Market Sentiment

This project looks at how traders behave during Fear and Greed market conditions.

## 🧠 Idea

Markets are driven by emotion.  
So I checked how trading performance changes with sentiment.

---

## ⚙️ Steps

- Cleaned both datasets  
- Matched them using date  
- Added sentiment to each trade  
- Compared profit, win rate, and leverage  

---

## 📈 Findings

- Greed → higher profit but unstable  
- Fear → more consistent results  
- Higher leverage during Greed  
- Better win rate during Fear  

---

## 🧾 Conclusion

Market sentiment affects trading decisions.

Simple idea:
- Control risk during Greed  
- Stay consistent during Fear
